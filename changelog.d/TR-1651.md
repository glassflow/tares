A permission you allowed on the console now reaches the crew's stations. It was only written into the grants doc, which station settings are not built from, so a station kept being refused the same command.
Allowing for every project now needs an admin; anyone else is refused and the item stays open. Allowing for one project needs its lead or an admin. On a team with the enterprise licence, anyone else's permission for the project now waits for the lead to agree, and any permission for the project, a lead's or an admin's too, also waits for the owner of a repo it names when that is someone else. Without the licence, anyone but the lead or an admin is refused.
Permissions you allowed on the console before this release have to be allowed again.
