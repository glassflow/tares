A permission you allowed on the console now reaches the crew's stations. It was only written into the grants doc, which station settings are not built from, so a station kept being refused the same command.
Allowing for every project now needs an admin; anyone else is refused and the item stays open. Allowing for one project takes effect at once for its lead or an admin. On a team with the enterprise licence, anyone else's permission for the project now waits for the lead to agree, and it can also wait for the owner of a repo it names. Without the licence it needs the lead or an admin.
Permissions you allowed on the console before this release have to be allowed again.
