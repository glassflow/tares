A crew station that keeps the Slack plugin or a Slack MCP server now starts with every Slack write tool denied by name (send, draft, schedule, canvas create and update, reaction) and a deny rule for a write verb, so a write tool the plugin adds later is denied too (T20). Before, a station that kept Slack could post; now it reads only. Reads (read, search, list, get) stay open. The rules are added to the station settings beside the ones it has and the person's, and only when the role keeps Slack.
