The console can run inside the Tares desktop app. Opened with `?embed=desktop`, it drops its own header, menu and drawer, so the desktop's rail and top bar are the only ones, and the page uses the whole width. `&theme=light` or `&theme=dark` paints the desktop's theme before the first paint, over the one saved in the console, and does not save it (TR-1553). The mode lasts for the tab, and a console opened without the parameter is unchanged.
