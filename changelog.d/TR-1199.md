Removing a repo from the brain now deletes everything the brain holds for it (TR-1199). The cell first cancels the repo's queued or running index at the control plane, then asks the brain to delete the repo and what it indexed from it, and only then takes the repo off the list. If the brain is still indexing the repo, removing waits up to two minutes and then says "Still indexing. Try again in a minute."; the repo stays on the list, and removing it again finishes the job. If the control plane cannot be asked, the repo stays and the message says to try again. While a repo is being removed, Retry and a second Remove answer 409.
