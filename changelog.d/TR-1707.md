Fixed
A NUL byte in any text of a posted Claude Code line no longer makes a cell on Postgres refuse the whole batch, or stop filling the commands and challenger records of its sessions at start. Every NUL is now dropped from a posted line, keys included, so SQLite and Postgres store the same text. Lines stored before keep their NULs where they are, and are written to Postgres without them. A trigger firing or a read recorded with one no longer stops the first start with a state database.
