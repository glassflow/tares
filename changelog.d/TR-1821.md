Added
A one-time script moves a Tares 1.61.0 cell to 2.0 (TR-1821). `uv run scripts/migrate_to_2.py --check <data dir>` checks the cell and prints what it will copy, rename, rebuild and leave behind, table by table; `--apply <data dir> --to <new folder or Postgres schema>` writes a new 2.0 store, checks it against the cell and only then stamps it `0001_baseline`. The cell itself is only read. `--state-dsn` names a cloud cell's Postgres. `scripts/MIGRATE_TO_2.md` is the runbook for a local cell and a cloud cell, with the way back.
