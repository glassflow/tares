Home shows a "Your team" panel to someone joining a factory another person set up (TR-1646). It comes first on the page and lists each person, with a mark for you and for admins and whether their crew is running or when it was last heard, then each open project you can see with a link and its lead, and says who answers a project's questions. The home data (`GET /api/home`) carries the same lists as `joiner.team` while you are joining. If the second read behind the joining page fails, Home now shows what the first read gave instead of an error, and the welcome heading is there while the first person's name loads.
