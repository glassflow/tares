On a crew that runs on Codex, a station's request beyond its sandbox (a fetch, a push, a write outside its workspace) is now decided by its rules, the person's grants among them, as a Claude Code station's auto mode decides it (TR-1599). Codex's own approval reviewer judges each request against a policy made of the station's rule sentences; it waited for the person on the desk before. The sandbox is never widened by a grant: a grant made later reaches a running station when the factory restarts it in the same conversation with the new policy, as it does on Claude Code. The guard still runs first, so a halted crew and the guard's refusals stop a request whatever a rule allows. Every decision, allowed or refused, is recorded as a `codex-review` event and said by the watch. A refused request is asked of the person the way a Claude Code station asks for a command its permission check denied. Claude Code crews are unchanged.
