Changed
Tares agents, Ask, triggers, schedules, agent dispatch, entity counts and agent tracing are removed (TR-1810). No code on the cell runs an agent, answers Ask, evaluates a trigger, delivers a firing to a subscriber, counts entities or exports agent traces. The routes for agents, Ask sessions, the agent chat, triggers, subscriptions, activity, MCP servers, skills, project findings and results, the practice run, the agent settings and the agent tracing settings are gone, and so are the MCP tools remember, list_skills, get_skill, list_findings, record_finding, join_project, create_trigger, update_trigger and subscribe. `/tares ask` in Slack now answers that asking from Slack is no longer available. The standup, milestone and report summaries still run on the cell's model provider and are still metered in /api/usage/model, and station telemetry still reads the TARES_TRACING_* settings. The default model is read from TARES_MODEL, then TARES_AGENT_MODEL. TARES_AGENT_DAILY_CAP is no longer read. The challenger workflow template is gone: an existing challenger workflow project opens as a custom project, and the factory's challenger review keeps working. An older database keeps its entity count tables and nothing reads them. opentelemetry-sdk and opentelemetry-exporter-otlp-proto-http are no longer dependencies. Plugin 0.6.14 stops shipping the session_end line and drops triggers from the tares skill.
