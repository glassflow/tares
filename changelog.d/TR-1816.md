Changed
A new Tares 2.0 cell builds its database from one revision, `0001_baseline`, with every table under its 2.0 name (TR-1816): projects are in `projects`, the docs and skills a project uses in `project_docs` and `project_skills`, and its history in `project_log`. The 1.x revisions and the tables only 1.x used are gone; a 1.x cell is converted by the one-time migration script. The project API no longer returns `template`, `params` or `last_error`, and the MCP tool `list_projects` no longer returns `template`.
