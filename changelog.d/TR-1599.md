Added
Stations of a crew on Codex can now message each other (TR-1599). A station calls the Tares tool `send_to_station`; the watch reads the call from the sender's own session, so the sender is always the station that sent it, and hands the message to the recipient as a new turn between its turns. A station that is in a turn, stopped, or held at its account's limit gets its messages afterwards, once, also after a crash of the watch. A message to a station that is not in the crew comes back to its sender, and what a station sent is taken when it stops. A retire that cannot read the station's last messages is refused (the station is kept, and `--drop-mail` retires it anyway), so a retired station loses nothing it sent. A station's message is never taken as the person's answer or consent. Claude Code crews keep SendMessage. A message's text is quoted in the turn, so it cannot pass for another station's; a message to a station retired before it was delivered goes back to its sender; `crew down --drop-mail` stops a station whose last messages cannot be read; `send_to_station` is refused on a cell whose stations run on Claude Code. The orchestrator, reviewer and releaser of a Codex crew now run in the crew's worktrees folder, so their sandbox cannot write the crew home.
