Fixed
A station on Codex is now woken by the factory even when idle_wake is off, and what the factory tells it after its first start asks for nothing it does not have (TR-1598). It holds no schedule of its own, so with idle_wake off it was never woken again; a revive, a plugin update, a helper's start and a new grant told it to reload skills, re-arm a Cron tick or message its parent. `tares factory doctor` now checks a running Codex station's connection to the Tares MCP endpoint: each server connected, and one read going through with the station's key. Claude Code crews are unchanged. `tares factory outcome` took its own name for the call it was given, so a Codex station could not settle a call cut off by a crash; it now lists the calls and settles one by its call id. A Codex station whose sandbox refused a command (a fetch or a push) was told to wait for a grant that a Codex station never gets; it now asks for approval, which reaches the desk. A Codex station can now write its report in the crew home without asking: its sandbox reaches the crew's reports folder and nothing else of the crew home.
