The cell can give a crew a GitHub token for one repository and say who to commit as: `GET /api/factory/github/token?repo=owner/name`, with a person's key (stations included). It answers for a repository that a project of that person names and that a stored github.com credential follows. A token from a GitHub App is short-lived and asks only for contents, pull requests, checks and metadata; a personal token goes to admin keys only and is handed out as stored (TR-1422).
