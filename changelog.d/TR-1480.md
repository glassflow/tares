Changed
The settings table now lives in the session store, and the local session store file is called tares.sqlite instead of sessions.sqlite (TR-1480). A start renames the old file and copies the settings in, and on Postgres the existing table is taken over as it is.
 The cell's edition, seed marker and upgrade markers now sit in tares.sqlite, so deleting tares.duckdb alone no longer resets a local cell: delete tares.sqlite beside it too.
